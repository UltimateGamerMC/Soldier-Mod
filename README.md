# Soldier Mod

A working squad for Minecraft. Enlist soldiers, give them standing orders, keep them in
formation, promote them by rank and watch them fight for you. Built for **Fabric**, on
**Minecraft 26.3**.

Everything is hand-made: six pixel-drawn uniforms, hand-placed 16x16 item icons and a
custom mod icon, all generated by `tools/make_assets.py`.

## The squad

| | |
| --- | --- |
| **Enlistment Papers** | Right-click to enlist a soldier bound to you. Sneak + right-click to change which class the next recruit will be. |
| **Squad Radio** | Right-click the air to recall the whole squad to your position. Sneak + right-click to change formation. Right-click a soldier to hand it the next order. |

## Orders

Every order is a real behaviour, not a flag.

| Order | What the soldier does |
| --- | --- |
| **Follow** | Falls into its slot in the squad formation and keeps up with you. |
| **Hold** | Stands its post. It will not follow you, even across the map. |
| **Guard** | Holds a position and engages anything hostile that comes near it. |
| **Patrol** | Walks a route around its post, fighting what it finds. |
| **Charge** | Hunts down the nearest hostile within 26 blocks and attacks. |
| **Regroup** | Drops everything and closes up on you. |
| **Retreat** | Breaks off combat and falls back to you. |

Issue orders by sneak + right-clicking a soldier, with the Squad Radio, or with
`/soldier order <order> [all]`.

## Formations

The squad falls in around you in **Wedge**, **Line** or **Column**. Change it with
sneak + right-click (Squad Radio) or `/soldier formation <name>`.

## Classes

| Class | Role |
| --- | --- |
| **Rifleman** | The baseline: extra attack damage. |
| **Medic** | Heals itself, you and any squadmate nearby for 2 HP every 3 seconds. |
| **Heavy** | Slower, but +6 HP, +8 armour and heavy knockback resistance. |
| **Scout** | 28% faster, sees 16 blocks further, and paints the nearest hostile with Glowing so the whole squad can see it. |

Retrain a soldier with `/soldier class <class>` or the Enlistment Papers class cycle.

## Ranks

Rank is earned on the battlefield. Each rank adds health and damage.

| Rank | Kills | Bonus |
| --- | --- | --- |
| Private | 0 | - |
| Corporal | 5 | +4 HP, +1 damage |
| Sergeant | 15 | +8 HP, +2 damage |
| Captain | 30 | +14 HP, +4 damage |

Soldiers announce their promotion and wear their chevrons on the name tag.

## Commands

- `/soldier recruit [class]`: enlist a soldier.
- `/soldier order <order> [all]`: order the nearest soldier, or the whole squad.
- `/soldier class <class>`: retrain the nearest soldier.
- `/soldier formation <formation>`: change the squad's formation.
- `/soldier list`: roll call, with rank, class, order and kills.
- `/soldier recall`: bring the whole squad to you.
- `/soldier dismiss`: honourably discharge the nearest soldier.
- `/soldier give [radio]`: the kit.

## Crafting

Everything is craftable from vanilla materials: iron, gold, paper, copper and redstone.
Recipes unlock as you pick up the ingredients.

## Building

```
./gradlew build
```

The jar lands in `build/libs/`. Assets are generated:

```
python3 tools/make_assets.py    # six 64x64 uniforms, two item icons, the mod icon
```
